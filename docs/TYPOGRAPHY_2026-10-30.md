# 잘난체 고딕과 무대 레이아웃 보정

## 재현한 문제

이번 요청에는 별도의 레이아웃 스크린샷 파일이 첨부되지 않아, 설명된 증상과 현재 공개된 한국어·영어 화면을 브라우저에서 기준으로 삼았다. 기존 475f32f 버전과 수정본을 Chromium의 CSS 뷰포트, 기본 확대율에서 비교했다.

- **1920×700:** 기존 제목 하단과 카드 상단이 약 42.7px 겹쳤다. 수식과 예시 입력이 같은 영역에 놓이고, 검토 명령과 하단 설명도 겹쳤다. 정지 장면에서도 남는 문제였다.
- **390×844:** 기존 수식의 하단보다 예시 입력 영역의 상단이 약 4.4px 높았다. 입력과 계산 결과를 위한 독립적인 행이 없었다.
- **헤더 가림:** 일반 장 클릭에서는 자동으로 재현되지 않았다. 다만 기존 `overflow:hidden` 무대가 내부 스크롤 컨테이너였고, 내부 위치를 96px 이동시키면 제목 상단이 약 139.4px에서 43.4px로 바뀌어 높이 64px의 헤더 뒤에 들어가는 조건을 확인했다. 새 무대는 `overflow:clip`을 사용해 별도의 내부 스크롤 위치가 생기지 않는다. 실제 장 이동, 직접 URL, 언어 전환과 글꼴 로딩은 별도로 검사했다.

## 서체와 출처

[공식 글꼴 페이지](https://gccompany.co.kr/font#download)의 **잘난체 고딕** 다운로드 링크에서 OTF 원본을 받았다. 파일은 단일 Regular 스타일이며 `OS/2.usWeightClass = 400`이다. `next/font/local`도 400/normal로 설정했다. 제목은 synthetic bold 없이 자간 0, 한국어 전용 크기·행간·두 줄 구성을 사용한다.

- 원본: `src/fonts/JalnanGothic.otf`, 1,723,800 bytes.
- SHA-256: `039cef18494d3b8ee13b46f75af3fc3122a607867b742aad6bba786c743625b1`.
- 공식 ZIP: `https://framerusercontent.com/assets/nDlVcfwW7fVXLTZeKX4WdTVY1Yk.zip`.
- 저작권 안내: `public/fonts/JalnanGothic-NOTICE.txt`.
- 공식 사용 가이드와 라이선스 전문: `public/fonts/JalnanGothic-Guide.pdf`, PDF 3페이지.

공식 가이드는 이미지 기반 PDF여서 페이지를 렌더링해 읽었다. 가이드의 수정·재배포 조건을 고려해 변환·서브셋·메타데이터 변경 없이 원본을 보관한다. 다운로드 원본과 저장된 파일의 해시가 일치한다. 글꼴은 사이트 MIT 라이선스에 포함되지 않는다.

한국어 hero·장면·읽기 모드 및 설치·결말의 큰 제목에 적용한다. 본문·메뉴·버튼·상태·파일 이름은 기존 본문 서체를 유지하고, 로고는 바꾸지 않는다. 영어는 Archivo, 수식·CLI는 monospace를 유지한다. 한국어 OTF는 선행 다운로드하지 않으며, 영어 경로에서는 요청되지 않음을 확인했다.

## 배치와 모션

한 무대와 820svh 스크롤 범위, 여섯 장면과 CLI 의미를 유지한다. 무대는 공통 Grid 행으로 헤더 여백, 제목, 제목–시각화 간격, 시각화, 피드백, 하단 설명, 탐색을 예약한다. 큰 화면의 남는 세로 공간은 구성 바깥의 유연한 여백으로 배분하고, 카드 높이는 상한을 두었다. 독립적인 `top`/`bottom` 좌표와 JS의 뷰포트별 카드 높이 계산을 제거했다.

카드는 파일 머리말, 수식, 예시 입력·계산 결과, 문서 문장·인용·값을 Grid 영역에 나눠 담는다. 변경 전후 문장은 같은 크기의 영역을 공유한다. 짧은 모바일에서는 결과 라벨과 숫자를 가로로 배치하며, essential label을 숨기지 않는다. 영향 장면에서는 같은 문서 열을 두 행으로 전환한다.

SVG 연결선은 실제 카드 경계에서 좌표를 구하므로 높이·폭·서체가 달라져도 붙어 있다. 마지막 장에서 고리로 전환되는 의미 있는 분리는 유지한다. 장면 전체를 위아래로 옮기던 효과를 제거하고 제목만 12px 이내에서 들어오게 해 설명과 탐색의 고정 영역을 지킨다. 카드의 초기 등장은 작은 이동·확대로 제한해 진입 중 내용이 화면 가장자리 밖으로 밀리지 않게 했다.

클릭·직접 URL·언어 전환은 하나의 seek 경로를 사용한다. ScrollTrigger의 스크롤 함수를 통해 캐시와 타임라인을 함께 갱신한다. 초기 장 이동과 refresh는 `document.fonts.load` 및 `document.fonts.ready` 이후에 실행하며, 글꼴 실패 시에도 fallback 상태로 계속 작동한다. 읽기 모드가 처음으로 돌아갈 때 언어 링크에 이전 장 주소가 남던 문제도 고쳤다. 정지 읽기, reduced motion, 로고 복귀와 일반 문서 스크롤은 유지한다.

## 검증

`npm run build`, `npm run lint`, `npm run typecheck`, 기존 단위 테스트 15개, 기존 브라우저 검사 182개, 새 `npm run test:layout`의 93개 검사를 실행했다.

새 검사는 한국어·영어를 각각 1366×768, 1440×900, 1920×1080, 2560×1440, 3840×2160, 1920×700, 390×844, 360×800 및 추가 320×640에서 검사한다. 여섯 장면의 정지 상태, 전환 중간과 역방향, 반복 장 클릭, 직접 `#evidence`·`#review`, 양방향 언어 전환, 전환 중 리사이즈, 차가운 글꼴 로딩, 실제 사용 글꼴(CDP), 내부 스크롤 방지를 확인한다. CSS 값을 재진술하는 대신 실제 경계 상자와 연결점·가시 콘텐츠를 비교한다.

| 뷰포트 | 제목–카드 간격 (한국어·영어) |
| --- | --- |
| 1366×768 / 1440×900 / 1920×700 | 48px |
| 1920×1080 | 54px |
| 2560×1440 | 72px |
| 3840×2160 | 80px |
| 390×844 / 360×800 | 24px |
| 320×640 | 16px |

1920×700에서 수식 영역과 예시 입력 영역의 간격은 한국어 약 31.7px, 영어 약 30.8px다. 정지 장면의 SVG 연결 오차는 0.01px 미만이었다.

## 로컬 산출물과 한계

`test-results/typography/`에 공개 사이트의 `before-live-*.png`, 로컬 기준의 `before-*.png`, 수정본 `after-*.png`, 전후 비교, 측정 JSON, 검사 JSON 및 한국어·영어·모바일 전환 녹화를 보관한다. 이 폴더는 Git 제외 대상이다. 원본 해상도 캡처와 카드 확대본으로도 확인했다.

실기기, Safari/Firefox와 보조공학의 수동 검증, 실제 GPU 성능은 확인하지 않았다. OTF는 라이선스를 존중해 원본 약 1.72MB를 사용하므로 서브셋 WOFF2보다 크다. 실제 저속 네트워크의 전송 성능은 측정하지 않았으며, 영어 페이지는 해당 파일을 받지 않는다.

이번 수정은 커밋·푸시·배포하지 않고 로컬에 남긴다. 기존 미추적 `AGENTS.md`는 그대로 보존한다.
